# Space-Run

A simple Game for XR-Interactive intern test.

#This Game is having:
- A player
- Who can:
  - Jump (Press Space)
  - Move (W,A,S,D)
  - Rotate (Mouse Rotation)
- The player need to save itself from different types of obstacles
- In the given times the player needs to reach to the Final Destination

#Game Over:
-If the player fall from the ground
-If the player fail to reach in the destination in the given time
